얌전한 작용의 등급 — 도장이 말썽을 부릴 때

핵심 질문 — 도장 찍기가 「얌전하다」는 건 정확히 무슨 뜻이고, 얼마나 얌전해야 접은 공간이 깔끔해질까?

15장에서 궤도로 접은 공간이 늘 깔끔하지는 않다고 했어요. 도장들이 한 동네를 「너무 자주」 자기 자신과 겹치게 하면 접은 공간에서 점들이 서로 떨어지지 못해요. 그 「얼마나 자주 겹치나」를 재는 도구가 운반자 집합이에요.

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을: 도장이 집합 A를 B와 겹치게 하는 횟수(운반자 집합)로 작용의 얌전함을 재고, 원자료의 네 등급을 비교합니다.
  2. 왜 중요한가: 얌전한 작용으로 접어야 접은 공간이 하우스도르프(09장)가 돼요. 17·18장의 타일·격자가 깔끔한 것도 작용이 얌전해서예요.
  3. 생활·현장에서는: 반복 무늬 설계, 결정 구조, 게임 지도의 「되풀이 맵」이 깨지지 않으려면 반복 규칙이 얌전해야 해요.

행렬·벡터, 복잡한 공식을 몰라도 됩니다. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

  • Bourbaki-proper — 부르바키 고유 작용 — 가장 센 얌전함

1단계 · 운반자 집합 — 겹치게 하는 도장 세기

방법: gA ∩ B ≠ ∅인 g 세기일상: 컨베이어 벨트 상자
박사

상황 질문 — 컨베이어 벨트 위 상자를 「n걸음」씩 옮겨요. 상자 A가 바닥 표시 B와 겹치게 되는 n은 몇 개일까요?

왜 이 방법을 쓰나

  1. 문제 상황: 작용이 「한 곳을 너무 자주 덮지 않는지」 재고 싶어요.
  2. 앞 방법의 한계: 15장의 궤도·안정자는 점 하나만 봤어요. 동네(집합)끼리 겹치는 정도는 몰랐어요.
  3. 해법: A를 B와 겹치게 하는 도장 모음 (A|B)_G를 세요. 이것이 유한하면 「A와 B 사이에선 얌전하다」고 봐요.
쉽게 말하면 — 상자를 몇 걸음 옮겨야 표시와 겹치는지 — 그 걸음 수가 유한하면 얌전하다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

(A|B)_G라는 괄호 표기는 처음 봐요. 어떻게 읽어요?

학교 수학으로 보면: 중학교 「조건을 만족하는 것의 모임」이에요. {g : gA ∩ B ≠ ∅}는 「gA와 B가 겹치는 g들의 모임」이라고 읽어요.

식 조각읽는 법뜻
gA지 에이도장 g로 A를 옮긴 것
gA ∩ B ≠ ∅지 에이와 비가 겹친다옮긴 A가 B와 만남
(A|B)_G에이에서 비로 가는 운반자 집합그런 g 전체
숫자로 한 번 해 보기

ℤ가 수직선에 「n만큼 옮기기」로 작용

A = [0, 2], B = [5, 6]

A + n = [n, n+2]가 [5, 6]과 겹치려면 n ≤ 6이고 n + 2 ≥ 5 → n = 3, 4, 5, 6

(A|B)_ℤ = {3, 4, 5, 6} → 4개, 유한

조수 하루 (수강생)

부등식 두 개만 풀면 겹치는 걸음 수가 나오네요!

일상으로 치면

상자 A를 n걸음씩 옮길 때 바닥 표시 B와 겹치는 n은 몇 개뿐이에요. 상자와 표시가 유한한 길이면 늘 그래요.

이산위상에서는

운반자 집합 (A|B)_G = {g : gA ∩ B ≠ ∅}. 모든 콤팩트 K에서 (K|K)_G가 유한하면 고유 불연속 작용(부르바키 고유)이에요. 수직선의 ℤ 평행이동은 고유 불연속이에요.

박사

A와 B의 자리를 바꿔 가며 초록 막대(겹치게 하는 n)를 세어 보세요.

주판봇

A를 길게 늘리면 n이 끝없이 많아지겠죠!

초파리 연구원

길어져도 유한한 길이면 유한 개야. 끝없이 많아지려면 A가 끝없이 길어야 해.

운반자 집합 — A를 몇 번 옮기면 B와 겹치나

풀이 — 한 걸음씩

  1. A = [0, 2], B = [5, 6]이면 n = 3, 4, 5, 6 — 4개.
  2. A, B가 유한한 길이(콤팩트)이면 늘 유한 개.
  3. 그래서 ℤ의 평행이동은 고유 불연속 작용 — 가장 얌전한 등급이에요.
  4. 이 작용으로 접은 ℝ/ℤ(원)는 깔끔한 하우스도르프 공간이에요(15장).
이 단계의 한계 — 운반자 집합을 세려면 「어떤 A, B를 볼지」를 정해야 해요. 등급마다 보는 집합이 달라서(2단계), 같은 작용이 한 등급은 통과하고 다른 등급은 실패할 수 있어요.
박사의 해석 — 얌전한 작용은 「유한한 동네를 유한 번만 덮는」 작용이에요. 운반자 집합이 그 「몇 번」을 세는 자예요.

이 장에서 가장 어려운 단계예요. 접어 둔 채 넘어가도 다음 장과 조교 대결을 읽는 데 문제없어요. 궁금하면 펼쳐 보세요.
2

2단계 · 카포비치 반례 — 자유롭고 떠도는데 얌전하지 않다

방법: 대각 행렬 [[2, 0], [0, 1/2]]일상: 늘였다 줄인 사진
박사

상황 질문 — 사진을 가로로 2배, 세로로 절반으로 바꾸는 버튼을 계속 누르면, 사진의 한 귀퉁이가 다른 귀퉁이와 몇 번이나 겹칠까요?

왜 이 방법을 쓰나

  1. 문제 상황: 「떠도는 작용」이면 충분히 얌전한지 확인하고 싶어요.
  2. 앞 방법의 한계: 1단계의 평행이동은 모든 등급을 통과해서 등급 차이가 보이지 않았어요.
  3. 해법: 구멍 뚫린 평면 ℝ² \ {(0, 0)}에 ℤ가 (x, y) → (2ⁿx, 2⁻ⁿy)로 작용하는 예를 봐요. 자유롭고 떠돌지만, x축 근처 동네 U와 y축 근처 동네 V를 끝없이 많은 도장이 겹치게 해요.
쉽게 말하면 — 늘였다 줄이기를 반복하면 한쪽 귀퉁이가 끝없이 다른 귀퉁이 근처로 다가간다.

벡터·행렬 첫걸음 — 대각 행렬 하나로 만든 반례

도장 g는 2 × 2 행렬 [2001/2] — 대각선에만 숫자가 있는 대각 행렬이에요. 가로는 2배, 세로는 절반.

행렬식 = 2 × 1/2 − 0 × 0 = 1. 넓이는 그대로인데 모양이 계속 찌그러져요. gⁿ은 [2ⁿ002⁻ⁿ]이에요(대각 행렬은 대각선 숫자만 거듭제곱하면 돼요).

n = −3: [1/8008] · (1, 1/8) = (1/8, 1) — x축 근처 점이 y축 근처로

n = −10: (1, 1/1024) → (1/1024, 1)

반지름 0.05 동네라도 n = −5, −6, …에서 모두 겹침 → 끝없이 많음

행렬·벡터를 처음 본다면 이 상자는 건너뛰어도 본문을 따라올 수 있어요.

일상으로 치면

가로 2배 · 세로 절반 버튼을 거꾸로 누르면, x축 근처 점 (1, 아주 작은 값)이 y축 근처 (아주 작은 값, 1) 쪽으로 계속 다가가요.

이산위상에서는

카포비치 반례: 점 (1, 2ⁿ)(n = −1, −2, …)에 도장 gⁿ을 찍으면 (2ⁿ, 1)이 돼요. 그래서 (1, 0) 근처 U와 (0, 1) 근처 V가 끝없이 많은 도장에서 겹쳐요. 작용은 자유롭고 떠돌지만 고유 불연속 작용이 아니고, 접은 공간은 하우스도르프가 아닌 다양체예요.

박사

반지름을 아주 작게 줄여도 겹치게 하는 도장 수가 어떻게 되나 보세요.

주판봇

반지름 0.05면 겹칠 일이 거의 없겠죠?

초파리 연구원

숫자를 봐. 살펴본 도장을 늘릴수록 겹치는 도장도 계속 늘어.

카포비치 반례 — (x, y) → (2x, y/2)

풀이 — 한 걸음씩

  1. 도장 g: (x, y) → (2x, y/2). 원점이 빠져 있어 어떤 점도 제자리가 아님 → 자유 작용.
  2. 점마다 작은 동네 U는 자기 자신과는 유한 번만 겹쳐요 → 떠도는 작용.
  3. 하지만 (1, 0) 근처 U와 (0, 1) 근처 V는 n = −1, −2, −3, …에서 끝없이 겹쳐요.
  4. 그래서 접은 공간에서 U와 V가 대표하는 두 점을 떼어 놓을 수 없어요 → 하우스도르프가 아님.
이 단계의 한계 — 이 반례는 공간이 「원점이 빠진 평면」이라 생겨요. 원점을 넣으면 원점이 모든 도장에 제자리라 자유 작용도 아니게 돼요.
박사의 해석 — 「점마다 얌전함」(떠돌기)과 「콤팩트마다 얌전함」(고유 불연속)은 달라요. 접은 공간이 깔끔하려면 더 센 쪽이 필요해요.
등급 이름이 헷갈리면 여기서 쉬어도 괜찮아요. 「행렬 [2001/2]은 넓이는 지키지만 얌전하지는 않다」 한 줄이면 충분해요.
원자료 인포그래픽 보기 (영어 그림)

원자료의 등급 그림과 아래 「Kapovich Counterexample」 상자.

원자료 등급 그림의 맨 아래 상자에 「For every compact subset K, (K|K)_G is finite.」가 두 번 적혀 있어 한 번만 씁니다.
원자료 맨 위 「Discrete Action」 문장이 「…group of homeomorphisms of」에서 끊겨 있어요. 이 페이지에서는 「G의 상이 X의 위상동형 군 안에서 이산적이다」로 마무리합니다.

모아가 AI에게 「자유롭고 떠도는 작용으로 접은 공간은 늘 하우스도르프인가요?」라고 물었어요.
