함자와 짝 — 이산 옷 입히기와 옷 벗기기

핵심 질문 — 집합에 이산 위상을 입히는 것과 공간의 위상을 벗기는 것은 왜 서로 「짝」일까?

기둥 4는 「이산 위상이 왜 특별한가」를 한 문장으로 말해요. 집합 S에 이산 위상을 입히는 번역기 Disc와, 공간 X에서 위상을 벗겨 점만 남기는 번역기 U가 있어요. 이 둘은 수반(짝) 관계 — 「이산 공간에서 나가는 연속 함수」와 「그냥 함수」가 정확히 하나씩 짝지어져요.

27개점 3개 집합 → 점 3개 공간으로 가는 함수 = 연속 함수 수 (출발이 이산일 때)

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을: 집합에 이산 위상을 입히는 Disc와 위상을 잊는 U가 「짝(수반)」임을, 연속 함수와 그냥 함수의 개수가 같다는 계산으로 확인합니다.
  2. 왜 중요한가: 「이산 위상은 가장 자유로운 위상」이라는 말의 정확한 뜻이에요. 이산 공간에서 나가는 함수는 아무렇게나 정해도 늘 연속이에요.
  3. 생활·현장에서는: 데이터를 「점 목록」으로 다룰 때(분류 라벨, ID 목록) 어떤 함수든 문제없이 정의되는 이유가 이 성질이에요.

행렬·벡터, 복잡한 공식을 몰라도 됩니다. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

영어 기호·약어 풀이 (펼치기)
  • Set — 집합들과 함수들의 세계(범주)
  • Top — 위상 공간들과 연속 함수들의 세계
  • Disc: Set → Top — 이산 함자 — 이산 위상 입히기
  • U: Top → Set — 망각 함자 — 위상 벗기기
  • Hom(A, B) — A에서 B로 가는 화살표(함수) 모음

왜 이 방법을 쓰나

조수 하루 (수강생)

「거꾸로 따라간다」 f⁻¹(V)는 어떻게 구해요?

학교 수학으로 보면: 중학교 「함수의 대응」이에요. f⁻¹(V)는 「f로 보냈을 때 V에 떨어지는 출발점들」을 모은 집합이에요. 역함수가 없어도 쓸 수 있어요.

식 조각읽는 법뜻
f: S → X에프, 에스에서 엑스로출발 S, 도착 X인 함수
f⁻¹(V)에프 역 브이V로 보내지는 출발점 모음
연속—모든 열린 V에 대해 f⁻¹(V)가 열림
숫자로 한 번 해 보기

출발 S = {a, b, c} (이산), 도착 X = {1, 2, 3}, 열린 집합 {∅, {1}, X}

f: a ↦ 2, b ↦ 1, c ↦ 3 → f⁻¹({1}) = {b}

이산 위상에서 {b}는 열린 집합 → 통과. 어떤 f를 골라도 f⁻¹(V)는 S의 부분집합이라 열림

출발을 밀착 위상으로 바꾸면 {b}는 열려 있지 않음 → 불연속

조수 하루 (수강생)

출발이 이산이면 심사할 게 없네요. 출발이 밀착이면 거의 다 떨어지고요!

복장 규정이 없는 행사엔 누구든 들어와요. 규정이 가장 엄격하면(밀착) 거의 아무도 못 들어와요.

연속 검사기 — 출발이 이산일 때와 밀착일 때

풀이 — 한 걸음씩

  1. 출발 {a, b, c}가 이산이면 27개 함수가 모두 연속.
  2. 출발이 밀착이면 f⁻¹({1})이 ∅이나 전체여야 해서, 대부분 불연속.
  3. 「출발이 이산이면 모두 연속」 = 이산 위상이 가장 자유로운 위상이라는 뜻.
  4. (거꾸로, 「도착이 밀착이면 모두 연속」 — 밀착 위상은 반대쪽 끝이에요.)
이 단계의 한계 — 「모든 함수가 연속」은 편하지만, 그만큼 연속이 아무 정보도 주지 않는다는 뜻이기도 해요. 이산 공간에서는 「연속」으로 모양을 구별할 수 없어요.

2단계 · 짝 관계 — 연속 함수 수 = 그냥 함수 수

방법: 함수 개수 세기 |X|^|S|일상: 옷 입히기·벗기기
박사

상황 질문 — 옷 가게에서 「옷을 입혀 보는 방법 수」와 「옷 없이 사람만 세는 방법 수」가 늘 같다면, 두 일은 어떤 관계일까요?

왜 이 방법을 쓰나

  1. 문제 상황: Disc와 U가 「짝」이라는 말을 숫자로 확인하고 싶어요.
  2. 앞 방법의 한계: 1단계는 「모두 연속」까지만 봤어요. 두 번역기의 관계는 말로만 남았어요.
  3. 해법: 연속 함수 Disc(S) → X의 모음과, 그냥 함수 S → U(X)의 모음이 하나씩 짝지어져요: Hom_Top(Disc(S), X) ≅ Hom_Set(S, U(X)). 개수로는 둘 다 |X|^|S|예요.
쉽게 말하면 — 이산 옷을 입혀 연속으로 보내는 방법 = 옷을 벗긴 쪽으로 그냥 보내는 방법.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

|X|^|S|는 왜 거듭제곱이에요?

학교 수학으로 보면: 중학교 「경우의 수」의 곱의 법칙이에요. 출발점마다 도착점을 하나씩 고르니, 출발점이 |S|개, 고를 곳이 |X|개면 |X| × |X| × … (|S|번).

식 조각읽는 법뜻
Hom_Top(Disc(S), X)이산 공간에서 X로 가는 연속 함수 모음왼쪽
Hom_Set(S, U(X))S에서 X의 점들로 가는 그냥 함수 모음오른쪽
≅하나씩 짝지어짐두 모음 사이 일대일 대응
숫자로 한 번 해 보기

S = {a, b, c}, X = 점 3개짜리 공간

그냥 함수 S → U(X): a, b, c마다 3가지 → 3 × 3 × 3 = 27

연속 함수 Disc(S) → X: 1단계에서 27개 모두 연속 → 27

27 = 27 → 짝 관계 확인. 출발을 밀착으로 바꾸면 연속 함수가 줄어 짝이 깨짐

조수 하루 (수강생)

이산 옷을 입혔을 때만 두 개수가 딱 맞네요!

벡터·행렬 첫걸음 — 함수 = 표 채우기, 개수 = 거듭제곱

함수 S → X는 「출발점마다 도착점을 적은 표」예요. 05장 0/1 표처럼, 표의 각 줄에 들어갈 수 있는 경우를 곱하면 개수가 나와요.

출발점 3개 × 도착점 3개를 0/1 표(3 × 3 행렬)로 적으면, 각 가로줄에 1이 정확히 하나씩 있는 표가 함수 하나예요. 그런 표는 3 × 3 × 3 = 27가지.

a ↦ 2, b ↦ 1, c ↦ 3의 표: [0 1 0] / [1 0 0] / [0 0 1]

가로줄마다 1을 어디에 둘지 3가지 → 27가지 표

행렬·벡터를 처음 본다면 이 상자는 건너뛰어도 본문을 따라올 수 있어요.

일상으로 치면

옷(위상)을 입히는 가게와 벗기는 가게가 짝이면, 「입혀서 보내는 방법」과 「벗겨서 보내는 방법」의 가짓수가 늘 같아요.

이산위상에서는

Disc ⊣ U: 수반 Hom_Top(Disc(S), X) ≅ Hom_Set(S, U(X)). 이산 함자는 망각 함자의 왼쪽 짝이에요. 이것이 「이산 위상은 집합 위의 가장 자유로운 위상」의 정확한 뜻이에요.

박사

이산 옷과 밀착 옷을 번갈아 고르며 두 개수를 비교하세요.

인턴 모아

이산 옷이면 27 = 27! 짝이 맞아요.

초파리 연구원

밀착 옷이면 왼쪽이 줄어. 그래서 짝은 「이산」 옷만이야.

함수 개수 세기 — 이산 옷과 밀착 옷 비교

풀이 — 한 걸음씩

  1. 이산 옷: 연속 함수 수 = 그냥 함수 수 = |X|^|S|.
  2. 밀착 옷: 연속 함수 수 < 그냥 함수 수 (도착 공간에 따라).
  3. 짝 관계는 「어떤 S, X에서도 하나씩 짝지어진다」는 약속이라, 이산 옷만 통과해요.
  4. 원자료 아래 공식 Hom_Top(Disc(S), X) ≅ Hom_Set(S, U(X))가 바로 이 계산이에요.
이 단계의 한계 — 수반은 「개수가 같다」보다 강한 말이에요(짝짓는 방법이 S, X를 바꿔도 자연스럽게 맞물림). 이 페이지는 개수로만 확인했어요.
박사의 해석 — 이산 위상은 「아무 조건도 붙이지 않은」 위상이라, 연속 함수가 그냥 함수와 같아요. 22장의 스톤-체흐는 같은 모양의 짝을 「콤팩트 하우스도르프」 쪽에서 만들어요.
원자료 인포그래픽 보기 (영어 그림 · 이론 구간)

원자료 오른쪽 상자 「Adjunction Theorem」과 아래 공식.

원자료 그림에서 Hom_Set 화살표가 U(X) → S 방향으로 그려져 있어요. 짝 관계의 오른쪽은 S → U(X) 방향의 함수 모음이에요.
원자료 오른쪽 상자의 「discrete topology topology」는 같은 말이 겹친 오타라 한 번만 씁니다.
