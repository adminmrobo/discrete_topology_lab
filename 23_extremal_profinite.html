06장에서 이산 공간은 완전히 끊긴 공간이었어요. 그보다 더 철저하게 끊긴 아주 끊긴 공간이 있어요 — 22장의 βℕ이 그 예예요. 그리고 유한한 이산 공간을 층층이 맞물려 끝없이 쌓은 프로유한 공간이 있어요. 둘 다 콤팩트하고 완전히 끊겼지만, 끊긴 「정도」가 달라요.

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을: 열린 집합의 닫힘이 늘 열린 「아주 끊긴 공간」과, 유한 이산 공간의 역극한인 「프로유한 공간」(예: p진 정수 ℤ_p)을 비교합니다.
  2. 왜 중요한가: 둘 다 「이산 공간에서 태어난 콤팩트 공간」이에요. 아주 끊긴 공간은 βℕ처럼 보편 성질에서, 프로유한 공간은 유한한 층을 쌓아서 나와요.
  3. 생활·현장에서는: 나머지 계산을 층층이 맞물려 쓰는 암호·오류 검출 코드, 끝없는 이진수로 수를 다루는 p진 계산이 프로유한 공간의 실제 쓰임이에요.

행렬·벡터, 복잡한 공식을 몰라도 됩니다. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

영어 기호·약어 풀이 (펼치기)

  • lim← — 역극한 — 맞물린 층들의 모음
  • ℤ_p — p진 정수 (이 페이지에서는 p = 2)
  • mod 2ᵏ — 2ᵏ으로 나눈 나머지

모든 층이 맞물리면 수 하나가 끝없는 2진수로 저장돼요. −1은 1이 끝없이 이어진 …1111이에요.

상황 질문 — 모래알처럼 끊긴 섬들이 0 쪽으로 점점 촘촘히 모여 있어요. 섬 몇 개를 고르면, 그 무리의 「물가까지 포함한 영역」도 깔끔한 섬 무리일까요?

왜 이 방법을 쓰나

  1. 문제 상황: 완전히 끊긴 공간 중 「더 철저한」 것을 구별하고 싶어요.
  2. 앞 방법의 한계: 06장의 완전히 끊김(연결 덩어리가 점 하나)은 이산 공간, 캔터 집합, βℕ을 모두 같은 등급으로 묶어 구별이 안 돼요.
  3. 해법: 「모든 열린 집합 U의 닫힘 cl U가 열려 있다」를 기준으로 삼아요. 이것이 아주 끊긴 공간이에요. 거리가 있는 공간에서 이 조건을 만족하면 이산 공간뿐이에요.
쉽게 말하면 — 어떤 섬 무리를 골라도, 물가까지 포함한 영역이 다시 깔끔한(열린) 섬 무리가 된다.

조수 하루 (수강생)

닫힘이 「열려 있다」는 게 왜 그렇게 특별해요?

학교 수학으로 보면: 02장의 닫힘(cl)과 경계예요. 보통 열린 집합의 닫힘에는 경계 점이 붙어서 더는 열려 있지 않아요. 아주 끊긴 공간에서는 경계 점이 붙어도 다시 열린 집합이에요.

식 조각읽는 법뜻
cl U유의 닫힘U와 그 경계를 합친 것
cl U가 열림—아주 끊긴 공간의 조건
캔터 집합가운데 1/3을 계속 지운 점들완전히 끊겼지만 아주 끊기진 않음
숫자로 한 번 해 보기

캔터 집합에서 0 쪽으로 모이는 조각들 중 「하나 걸러 하나」를 골라 U로 삼기

U는 열린 집합(조각들의 합)이고, 그 닫힘에는 0이 붙음

0 둘레의 어떤 동네에도 「고르지 않은」 조각이 들어옴 → cl U는 0에서 여유가 없어 열려 있지 않음

→ 캔터 집합은 아주 끊긴 공간이 아님

조수 하루 (수강생)

하나 걸러 고르면 0이 경계에 걸리는군요. 그래서 「아주」가 아니에요.

일상으로 치면

0 쪽으로 모이는 모래섬 중 하나 걸러 하나를 고르면, 물가(0)를 포함한 영역은 0 근처에 고르지 않은 섬이 끼어들어 깔끔한 섬 무리가 되지 못해요.

이산위상에서는

아주 끊긴 공간: 모든 열린 U의 닫힘이 열려 있는 공간. 이산 공간과 βℕ은 아주 끊겼고, 캔터 집합은 완전히 끊긴 공간이지만 아주 끊기진 않았어요. 글리슨 정리(1958): 콤팩트 하우스도르프 공간 범주의 사영 대상은 정확히 아주 끊긴 콤팩트 하우스도르프 공간(스톤 공간)이에요.

풀이 — 한 걸음씩

  1. 캔터 집합: [0, 1]에서 가운데 1/3을 끝없이 지운 점들 — 완전히 끊김.
  2. 0 쪽으로 모이는 조각을 하나 걸러 고른 U의 닫힘에 0이 들어와요.
  3. 0 둘레엔 고르지 않은 조각이 늘 있어서 cl U는 열려 있지 않아요 → 아주 끊긴 공간이 아님.
  4. βℕ에서는 이런 일이 생기지 않아요(울트라필터가 「하나 걸러」 고른 쪽과 나머지 쪽 중 하나만 「큼」으로 정해서).

박사의 해석 — 끊김에도 등급이 있어요: 하우스도르프 공간에서는 이산 ⊂ 아주 끊김 ⊂ 완전히 끊김(점이 둘 이상인 밀착 공간은 열린 집합이 ∅과 전체뿐이라 「아주 끊김」 조건을 저절로 통과하지만 연결이에요. 그래서 하우스도르프라는 조건이 필요해요). 거리가 있는 공간에서는 「아주 끊김 = 이산」이라, 아주 끊긴 무한 콤팩트 공간(βℕ)은 거리로 잴 수 없는 공간이에요.

  1. 문제 상황: 유한한 것만으로 무한한 콤팩트 공간을 만들고 싶어요.
  2. 앞 방법의 한계: 22장 βℕ은 「존재」로만 다뤘어요. 손으로 만들 수 있는 방법이 필요해요.
  3. 해법: 유한 이산 공간 ℤ/2, ℤ/4, ℤ/8, …을 「나머지 줄이기」 지도로 이어 놓고, 층마다 하나씩 고르되 맞물리는 선택(x_k를 2^(k−1)로 나누면 x_(k−1))만 모아요. 이것이 역극한 ℤ₂ = lim← ℤ/2ᵏ, 2진 정수예요.
쉽게 말하면 — 톱니가 맞물린 시계들 — 큰 시계의 바늘이 정해지면 작은 시계 바늘이 저절로 정해진다.
이론 구간 — 수식으로 보기 · 벡터·행렬 첫걸음
시아·모아도 머리를 감싼 곳이에요. 몰라도 그림 실험과 풀이를 따라올 수 있어요. 궁금하면 펼쳐 보세요.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

−1의 나머지가 1, 3, 7, 15, …라는 건 어떻게 나와요?

학교 수학으로 보면: 나머지 계산이에요. −1을 8로 나눈 나머지는 7 (−1 = 8 × (−1) + 7). 음수의 나머지도 0 이상 나누는 수 미만으로 맞춰요.

식 조각읽는 법뜻
x_k ∈ ℤ/2ᵏ케이층의 나머지2ᵏ으로 나눈 나머지 (0 ~ 2ᵏ − 1)
π: x_k ↦ x_k mod 2^(k−1)줄이기 지도위층 나머지를 아래층으로 줄이기
lim← ℤ/2ᵏ = ℤ₂역극한 = 2진 정수모든 층이 맞물린 선택들의 모음
숫자로 한 번 해 보기

−1의 나머지: mod 2 → 1, mod 4 → 3, mod 8 → 7, mod 16 → 15, …

맞물림 확인: 7을 4로 나눈 나머지 3 ✔, 3을 2로 나눈 나머지 1 ✔

2진수로 쓰면 1, 11, 111, 1111, … → 왼쪽으로 끝없는 …1111

…1111 + 1 = …0000 = 0 (자리올림이 끝없이 왼쪽으로) → 정말 −1처럼 행동!

조수 하루 (수강생)

−1이 1이 끝없이 이어진 이진수라니! 더하기까지 맞아떨어지네요.

벡터·행렬 첫걸음 — 맞물린 선택 = 끝없이 긴 숫자 줄(벡터)

프로유한 공간의 점 하나는 층마다 고른 나머지를 줄 세운 끝없는 벡터 (x₁, x₂, x₃, …)예요. 원자료의 「곱 공간 ∏ X_i의 부분공간」이 바로 이 「끝없는 벡터들 중 맞물린 것만」이라는 뜻이에요.

덧셈도 자리마다 해요: (x₁, x₂, …) + (y₁, y₂, …) = (x₁ + y₁ mod 2, x₂ + y₂ mod 4, …). 그래서 ℤ₂는 군이 돼요.

−1 = (1, 3, 7, 15, …), 1 = (1, 1, 1, 1, …)

합: (1+1 mod 2, 3+1 mod 4, 7+1 mod 8, …) = (0, 0, 0, …) = 0 ✔

행렬·벡터를 처음 본다면 이 상자는 건너뛰어도 본문을 따라올 수 있어요.

일상으로 치면

톱니가 맞물린 시계 묶음에서 가장 큰 시계의 바늘만 알면 작은 시계 바늘이 모두 정해져요. 시계를 끝없이 크게 이어 붙인 것이 프로유한 공간이에요.

이산위상에서는

프로유한 공간은 유한 이산 위상 공간들의 역극한이에요. ℤ₂ = lim← ℤ/2ᵏ은 콤팩트, 하우스도르프, 완전히 끊긴 공간이고, 덧셈이 층마다 맞물려 군(프로유한 군)이에요. 하지만 거리를 줄 수 있는 무한 공간이라 아주 끊기진 않았어요(βℕ과 다름).

박사

층마다 나머지를 골라 맞물리게 쌓아 보세요. 하나라도 어긋나면?

주판봇

음수는 나머지 줄을 못 만드니까 −1은 2진 정수가 아니겠죠…

초파리 연구원

−1도 층마다 나머지가 있어. 1, 3, 7, 15 — 완벽히 맞물려.

나머지 층 쌓기 — 맞물리게 맞추기

풀이 — 한 걸음씩

  1. 층 k에서 0 ~ 2ᵏ − 1 중 하나를 고르고, 아래층과 맞물리는지(줄이면 아래층 값) 확인해요.
  2. 모든 층이 맞물린 선택 하나가 ℤ₂의 점 하나 — 정수 n은 (n mod 2, n mod 4, …)로 들어가요.
  3. −1 = (1, 3, 7, 15, …) = …1111. 정수가 아닌 2진 정수(예: …010101)도 있어요.
  4. 층이 유한한 이산 공간이라 각 층은 콤팩트, 그 역극한도 콤팩트예요(티호노프 정리).
이 단계의 한계 — 이 페이지는 p = 2만 계산했어요. 원자료의 ℤ_p는 어떤 소수 p로도 같은 방법(mod p, p², p³, …)으로 만들어요.
박사의 해석 — 프로유한 공간은 「유한 이산 공간을 끝없이 맞물려 쌓은」 공간이에요. 이산 위상이 콤팩트한 무한 공간의 재료가 되는 두 번째 방법이에요.
원자료 인포그래픽 보기 (영어 그림 · 이론 구간)

원자료 「Profinite Spaces and Groups」의 세 상자와 층 그림.

원자료의 호환 조건 「π_ij ∘ φ_i = φ_j」는 역극한 원소의 조건으로 읽기 어려워요. 이 페이지에서는 「층마다 고른 x_i가 줄이기 지도로 맞물린다: π_ij(x_i) = x_j」로 바꿉니다.
원자료 제목은 「Spaces and Groups」인데 군 내용이 없어요. 이 페이지는 ℤ₂의 덧셈이 층마다 맞물려 프로유한 군이 된다는 것을 보탰어요. 그림의 π₁₁, π₁₂, π₁₃ 같은 라벨은 층 사이 지도와 맞지 않아 쓰지 않았어요.
