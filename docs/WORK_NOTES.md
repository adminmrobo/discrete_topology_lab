## 2. 원자료 바로잡기 (「원자료의 A를 이 페이지에서는 B로 바꿉니다」)

- 03장 2단계 (원자료 그림 02): 원자료의 「두 기저 원소의 교집합이 세 번째 원소를 포함한다」를 이 페이지에서는 「교집합의 각 점 x마다 x ∈ B₃ ⊆ B₁ ∩ B₂인 B₃가 있다」로 바꿉니다. 느슨한 문장으로는 블록 {1,2,3}, {2,3,4}, {3}이 통과하지만 위상이 만들어지지 않아요.
- 06장 2단계 (원자료 그림 05): 원자료 아래 그림 두 개가 서로 바뀌어 있어요. 「A를 피하는 길」 그림은 오른쪽 ℝ² 반례(07장)에, 점마다 네모 친 그림은 왼쪽 「완전히 끊김」에 맞아요. 이 페이지에서는 바꿔서 설명합니다.
- 08장 2단계 (원자료 그림 04): 원자료의 「ℝⁿ」 예시는 ℝⁿ 전체가 콤팩트인 것처럼 읽혀요. 이 페이지에서는 「ℝⁿ의 닫혀 있고 유계인 집합(예: 닫힌 상자)은 콤팩트, ℝⁿ 전체는 콤팩트가 아니다」(하이네–보렐)로 바꿉니다.
- 10장 1단계 (원자료 그림 06): 원자료의 「모든 열린 집합은 유한 개 기본 열린 집합의 합집합」을 이 페이지에서는 「점마다 가장 작은 열린 이웃 O_P가 있고, 모든 열린 집합은 O_P들의 (개수 제한 없는) 합집합」으로 바꿉니다. 무한 이산 공간 ℤ에서 짝수 전체는 열린 집합이지만 O_P 유한 개의 합이 아니에요.
- 10장 2단계 (원자료 그림 08): 원자료가 「반위상 공간(성격 1)」에 붙인 설명(점마다 가장 작은 이웃 O_P, 열린 집합은 그 합집합)은 오늘 1단계의 알렉산드로프 공간 정의와 겹쳐요. 이 페이지에서는 「교집합 규칙을 바꾼 느슨한 구조」로만 설명하고, 원자료 용어의 출처는 확인이 필요하다고 표시합니다.
- 11장 2단계 (원자료 그림 06): 원자료의 「알렉산드로프 공간과 부분순서 집합은 엄격히 동치」를 이 페이지에서는 「알렉산드로프 공간 ↔ 준순서, 그중 점이 구별되는(T0) 공간 ↔ 부분순서」로 바꿉니다. 밀착 위상(점 2개 이상)은 알렉산드로프 공간이지만 부분순서로 그릴 수 없어요.
- 13장 2단계 (원자료 그림 07): 원자료의 「열린 집합은 홀수 점 (2n+1, 2n+1), 닫힌 집합은 짝수 점」은 「열린 점(가장 작은 이웃이 자기 하나)은 두 좌표가 모두 홀수, 닫힌 점은 모두 짝수」로 바꿉니다. 점 하나와 집합을 섞어 쓴 표현이에요.
- 13장 2단계 (원자료 그림 07): 원자료 「Digital Continuity」의 「특별 연속(열린 점이 섞인 점으로 가지 않음)」 정의는 출처 확인이 필요해요. 이 페이지는 보통의 연속(열린 집합을 거꾸로 따라가도 열린 집합)으로 설명합니다. 오른쪽 위 그림의 축 이름(ℝ, i₁, r₁ 등)도 정수 격자와 맞지 않아 설명에 쓰지 않았어요.
- 16장 2단계 (원자료 그림 10): 원자료 등급 그림의 맨 아래 상자에 「For every compact subset K, (K|K)_G is finite.」가 두 번 적혀 있어 한 번만 씁니다.
- 16장 2단계 (원자료 그림 10): 원자료 맨 위 「Discrete Action」 문장이 「…group of homeomorphisms of」에서 끊겨 있어요. 이 페이지에서는 「G의 상이 X의 위상동형 군 안에서 이산적이다」로 마무리합니다.
- 17장 1단계 (원자료 그림 11): 원자료의 「닫힌 부분집합 F가 각 궤도와 정확히 한 점에서 만나면 엄격한 기본 집합」은, ℤ가 ℝ에 작용하는 쉬운 경우에도 [0, 1)은 닫혀 있지 않고 [0, 1]은 0과 1 두 점을 가져서 거의 성립하지 않아요. 이 페이지에서는 「궤도마다 한 점 = 기본 집합」과 「닫혀 있고 옮긴 조각들의 안쪽이 겹치지 않으며 전체를 덮음 = 기본 영역」으로 나누어 씁니다.
- 20장 2단계 (원자료 그림 13): 원자료 표 2행의 「X̃와 X 사이의 중간 덮개 ≅ 갈루아 확대 K/F의 중간체」는 서로 같다(≅)는 뜻이 아니라 「닮은 구조」(유비)예요. 이 페이지에서는 덮개 쪽은 「π₁(X)의 부분군」과 정확히 짝짓고, 체 쪽 이야기는 비유로만 씁니다.
- 20장 2단계 (원자료 그림 13): 원자료 표 2행의 「X̃~」는 「X̃」(보편 덮개)의 오타로 보고 고쳐 씁니다.
- 21장 1단계 (원자료 그림 19): 원자료의 「이산 함자 Disc: Set → Top은 집합 S를 대상이 S이고 항등 사상만 있는 범주로 바꾼다」는 「이산 범주」의 설명이에요. 이 페이지에서는 「Disc는 집합 S에 이산 위상을 입혀 위상 공간 Disc(S)를 만든다」로 바꿉니다.
- 21장 2단계 (원자료 그림 19): 원자료 그림에서 Hom_Set 화살표가 U(X) → S 방향으로 그려져 있어요. 짝 관계의 오른쪽은 S → U(X) 방향의 함수 모음이에요.
- 21장 2단계 (원자료 그림 19): 원자료 오른쪽 상자의 「discrete topology topology」는 같은 말이 겹친 오타라 한 번만 씁니다.
- 22장 2단계 (원자료 그림 14): 원자료 오른쪽 그림의 화살표 라벨 「continuous map f disconnects」의 「disconnects」는 뜻이 통하지 않아 「연속 함수 f」로만 읽습니다.
- 22장 2단계 (원자료 그림 14): 원자료의 「X에서 K로 가는 연속 함수가 βX를 통해 하나뿐으로 분해된다」는 X가 티호노프 공간일 때 X가 βX 안에 그대로 들어간다는 전제가 있어요. 이산 공간 ℕ은 이 전제를 만족해요.
- 23장 1단계 (원자료 그림 16): 원자료 그림의 큰 화살표 「Paradoxical Nature」(역설적 성질)는 정의와 관계없는 장식이라 설명에 쓰지 않았어요. 원자료의 다른 문장(거리 공간에서는 이산, 캔터 집합은 아님, 글리슨 정리)은 맞아요.
- 23장 2단계 (원자료 그림 17): 원자료의 호환 조건 「π_ij ∘ φ_i = φ_j」는 역극한 원소의 조건으로 읽기 어려워요. 이 페이지에서는 「층마다 고른 x_i가 줄이기 지도로 맞물린다: π_ij(x_i) = x_j」로 바꿉니다.
- 23장 2단계 (원자료 그림 17): 원자료 제목은 「Spaces and Groups」인데 군 내용이 없어요. 이 페이지는 ℤ₂의 덧셈이 층마다 맞물려 프로유한 군이 된다는 것을 보탰어요. 그림의 π₁₁, π₁₂, π₁₃ 같은 라벨은 층 사이 지도와 맞지 않아 쓰지 않았어요.
- 24장 2단계 (원자료 그림 20): 원자료 결론 그림 오른쪽 도식의 화살표 이름(Disc → Set → Set, U, Top, Inverse 등)은 21~23장의 정확한 관계(Disc ⊣ U, β ⊣ U, 역극한)와 맞지 않아요. 이 페이지에서는 그 도식을 쓰지 않고 글로 정리합니다.
